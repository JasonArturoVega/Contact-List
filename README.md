# Java Contact Book

A simple contact book application built in Java with a graphical user interface using Swing.

## Features

- Add contacts (number, name, and email)
- Edit existing contacts
- Delete contacts
- Search for contacts by name
- Prevent duplicate numbers
- Automatic saving and loading of contacts when closing and opening the program respectively

(https://github.com/JasonArturoVega/Contact-List/blob/master/src/Images/Screenshot.png)

## Technologies Used

-Java
-IntellJ IDEA
-Swing
-File handling (BufferedReader / BufferedWriter)
- HashMap for storing contacts

## How to Use

1. Enter the number and name (email is optional)
2. Click "Add Contact"
3. Select a contact from the table to "Edit" or "Delete"
4. Use "Search name" to find a contact by name
5. Contacts are automatically saved when closing the window

## How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA (or your preferred IDE)
3. Run the "MainExecution" class

## Key Takeaways

- Using "HashMap" with key-value pairs
- Separation of model, logic, and interface
- Working with "JTable" and "DefaultTableModel"
- Data persistence in text files
- Basic validation and duplicate handling
- Searching for elements within a collection
